## Getting Started

### Prerequisites
- Node.js v18+
- MongoDB
- Stripe account
- Claude/OpenAI API keys

### Installation
```bash
# Backend
cd backend
npm install
cp .env.example .env
npm run dev

# Frontend
cd frontend
npm install
npm start
```
